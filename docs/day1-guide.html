Module 2

Read a Photoresistor

Your first sensor. A photoresistor changes its electrical resistance based on how much light hits it. You'll wire it up, read the value it produces, and watch it change in real time.

Concept

The Feather Logger has analog input pins that can measure voltage. Your photoresistor module outputs a voltage that changes with light level — higher voltage means more light. The board converts this to a number between 0 and 65535.

Module 3

Add a Temperature & Humidity Sensor

Your first digital sensor. Unlike the photoresistor, this sensor does its own math internally and sends you calibrated numbers over a protocol called I2C. You'll wire it up and read temperature and humidity values.

Concept

I2C is a way for a microcontroller to talk to many sensors over just two wires — one for data (SDA) and one for a clock signal (SCL). Each sensor has a unique address, like a house number, so the board knows who it's talking to.

Module 4

Log Data to the SD Card

Right now your sensor data disappears the moment it's printed. In this module you'll save it to the SD card so you can keep it, open it on a computer, and graph it. This turns your board into a real data logger.

Concept

Your code will open a file on the SD card, write a new line of data every few seconds, and keep the file updated. The output is a CSV file — a plain text format that spreadsheet programs and graphing scripts can read directly.

Steps

1

Format and insert the SD card

Make sure the SD card is formatted as FAT32. Insert it into the slot on the Feather Logger.

If the SD card has old files on it, delete them or reformat before starting. Old data files can cause confusion when you're reading your results later.
2

Upload the logging sketch

Open the logging example code and upload it. This sketch reads from the temperature sensor and writes each reading to a file called data.csv on the SD card.

[PLACEHOLDER — logging code]
3

Let it run

Let the board log data for at least 2–3 minutes. You'll see confirmation messages in the Serial Monitor each time a row is written.

The Serial Monitor is showing a confirmation message each time a row is saved to the SD card.
4

Read the data

Unplug the board, remove the SD card, and insert it into a computer. Open data.csv — you should see a table of timestamps, temperatures, and humidity values.

You can open the CSV file and see rows of real data from your sensor.

Graph your data
